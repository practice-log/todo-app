# todo-app
JavaScript学習の一環として作成したタスク管理アプリです。  
本アプリは試作を重ねた5代目に当たり、DOMの直接操作からデータ（配列）へ処理の中心を移行するなど、構造改善を行いながら開発しました。

## 機能
- タスクの追加（ボタン / Enterキー）
- タスクの削除（ボタン）
- リセットボタン（リスト全消去）
- 完了状態の切り替え（取り消し線の表示）
- ソート機能（未完了タスクを上に表示）
- localStorageによるデータ保存

## 技術
- HTML
- CSS
- JavaScript（イベント処理・DOM操作）
- localStorage（データ永続化）

##  工夫した点
- タスクデータを配列で管理し、データを基軸とした処理になるよう設計しました。
- 各操作（追加・削除・完了）ごとに "save()" "render()" を呼び出し、内部データと表示で一貫性を保つよう構成しました。
- 各タスクに状態（"completed"）を持たせることで、表示変更やソート処理を実装しました。
- 利便性向上のため、Enterキーで追加できるよう調整しました。

## 今後の改善点
- リストおよび含まれるボタン類とorderの管理を "index" から "id" へ移行する
- タスクの順序管理の根拠を"Date.now()" からインクリメント方式へ変更する（順序管理の明確化）
- イベント移譲により "render()" 内を簡素化する
- UI / UX の改善 （レイアウトや操作性の改良）
