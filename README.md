# todo-app
ブラウザ上で動作するタスク管理アプリです。

## Demo
https://practice-log.github.io/todo-app/

## 概要
コーディングへの感触や適性を確認するため、JavaScriptにて作成しました。   
本アプリは試作を重ねた5代目に当たり、DOMの直接操作からデータ（配列）へ処理の中心を移行するなど、構造改善を行いながら開発しました。

## 機能
- タスクの追加（ボタン / Enterキー）
- タスクの削除（ボタン）
- リセットボタン（リスト全消去）
- 完了状態の切り替え（取り消し線の表示）
- ソート機能（未完了タスクを上に表示）
- `localStorage`によるデータ保存

## 技術
- HTML
- CSS
- JavaScript（イベント処理・DOM操作・データ管理）
- `localStorage`（データ永続化）

## 工夫した点
- タスクデータを配列で管理し、データを基軸とした処理になるよう設計しました。
- 各操作（追加・削除・完了）ごとに `save()` `render()` を呼び出し、内部データと表示が一致するよう構成しました。
- 各タスクに状態（`completed`）を持たせることで、表示変更やソート処理を実装しました。
- 利便性向上のため、Enterキーで追加できるよう調整しました。

## 今後の改善点
- ~タスクおよびボタン類の管理を`index`依存から`id`ベースへ移行する~ （完了）
- ~タスクの順序管理の根拠を`Date.now()`からインクリメント方式へ変更する（順序管理の明確化）~ （完了）
- イベント移譲により`render()`内を簡素化する
- UI / UX の改善 （レイアウトや操作性の改良）
- タスクの順序管理について、`order`を廃止し`id`に統合する（データ構造の簡素化）
- `id`生成の`length`依存を、より一意性の担保できる形へ変更する
- `id`の生成ロジックをデータ生成（`tasks.push`）から独立させる
